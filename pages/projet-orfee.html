Schéma de la base de données

Difficultés rencontrées & solutions

Problème

Base de données fragmentée : une table par type de bijou (alliance, clou…), rendant toute requête multi-catégorie impossible.

Solution

Refonte en table unique produits + categories hiérarchique avec parent_slug, permettant de requêter n'importe quelle combinaison.

Problème

Panier uniquement en $_SESSION : perdu à la fermeture du navigateur, non partageable entre appareils.

Solution

Panier persistant en BDD pour les comptes + session pour les visiteurs, avec fusion automatique mergePanierSession() à la connexion.

Problème

SITE_URL codé en dur causait une erreur 500 immédiate sur WAMP selon l'emplacement du dossier.

Solution

Auto-détection dynamique via $_SERVER['DOCUMENT_ROOT'] — fonctionne quel que soit l'emplacement dans le serveur.
